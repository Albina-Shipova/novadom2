Страницы и поисковая структура

  • Готово

    Заголовки и описания всех 26 страниц

    Проверены уникальные title и description главной, контактов, портфолио и 23 проектов. Описания проектов формируются из их видимого содержания, а география работы отражена на ключевых страницах.

  • Готово

    Основной адрес для каждой страницы

    Добавлены абсолютные canonical-ссылки на текущем домене novadom.asama.site. Они согласованы с картой сайта и указывают предпочтительный адрес каждого материала.

  • Готово

    Карта сайта с изображениями

    Создан sitemap.xml на 26 адресов. Для каждой страницы указано основное изображение. В карту включены только содержательные страницы сайта; этот служебный отчёт в неё не входит.

  • Готово

    Правила обхода для поисковых роботов

    Подготовлен robots.txt: открытые страницы разрешены для обхода, указан адрес sitemap, служебные каталоги и рабочие файлы исключены из обхода.

Представление студии и проектов

  • Готово

    Структурированные данные Schema.org

    Добавлена JSON-LD-разметка организации, сайта, услуг, контактов и портфолио. В ней указаны название студии, Анна Царева, телефон, логотип и города работы — Тула и Москва.

    Иерархия страниц и список проектов

    На внутренних страницах добавлены видимые хлебные крошки с соответствующей разметкой BreadcrumbList. ItemList объединяет 23 проекта в коллекцию. Посетители могут перейти к родительскому разделу, а поисковики получают связи между страницами.

  • Готово

    Превью ссылок в социальных сетях

    Настроены Open Graph и Twitter Cards: название, описание, абсолютный адрес и основная фотография каждой страницы. При отправке ссылки сервис получает данные для её превью.

  • Готово

    Корректные сведения о работах

    В разметку не добавлены неподтверждённые рейтинги и адрес офиса. Материалы другого бюро не представлены как авторский дизайн студии «Нова Дом».

ИИ-поиск и загрузка страниц

  • Готово

    Явные правила для ChatGPT, Claude и Perplexity

    В robots.txt добавлены OAI-SearchBot, ChatGPT-User, Claude-SearchBot, Claude-User, PerplexityBot и Perplexity-User. Открытые страницы разрешены, ограничения на служебные файлы повторены в группе ИИ-агентов. Правила проверены локально.

  • Готово

    Справочник студии в llms.txt

    Создан llms.txt с услугами, телефоном, часами работы, контактами и ссылками на 23 проекта. На всех 26 страницах добавлена ссылка describedby для обнаружения справочника. Этот предложенный формат дополняет сайт; его поддержка и появление в ИИ-ответах не гарантируются.

  • Готово

    Предзагрузка основных изображений

    Для главного изображения каждой страницы добавлен preload с высоким приоритетом. Галереи сохраняют отложенную загрузку: второстепенные фотографии не должны конкурировать с основным изображением.

  • Готово

    Отложенное подключение основного скрипта

    Скрипт интерактивных элементов подключается с defer. Он не блокирует разбор HTML и выполняется после подготовки документа. Работа проверенных страниц в браузере — без JavaScript-ошибок.

  • Готово

    Фирменное превью главной

    Подготовлена отдельная карточка 1200 × 630 пикселей с логотипом и интерьером студии, весом около 137 КБ. В Open Graph указаны размеры, формат и альтернативное описание. На внутренних страницах остаются фотографии соответствующих проектов.

  • Готово

    Векторный фавикон

    На 26 страницах подключён SVG-символ из фирменного логотипа. Существующий ICO сохранён как запасной вариант для браузеров.

с «Имидж Авто»

Сопоставлены все 23 пункта отчёта «Имидж Авто» с файлами «Нова Дом». Ниже — различия, которые остаются после дополнений. Автомобильные разделы и тип AutoRepair заменены соответствующей структурой студии интерьеров.

  • Нужен код

    Подтверждение Яндекс Вебмастера

    Для «Имидж Авто» есть проверочный файл. Для «Нова Дом» нужен собственный код из кабинета владельца; чужой файл не переносился.

  • Нужен сервер

    Снять запрет индексирования и опубликовать SEO-файлы

    11 ноября публичный сайт возвращает X-Robots-Tag: noindex, nofollow. robots.txt, sitemap.xml и llms.txt возвращают 404. В локальной версии файлы готовы. Для nginx подготовлен пример правил, включая /index.html → / и защиту служебных каталогов.

  • Уже работает

    HTTPS, HTTP-перенаправление и сжатие

    Публичный HTTPS проверен: сертификат действителен до 3 января 2027 года. Переход с HTTP сохраняет путь и параметры, HTML сжимается gzip. Перенаправление /index.html на / ещё не настроено. Вариант с www не подтверждён и не добавлялся.

  • Частично

    Адаптивные изображения и сжатие галерей

    Фотографии проектов уже используются в WebP, для портрета есть srcset, а изображения галерей загружаются отложенно. Отдельная облегчённая версия главного баннера и дополнительное пакетное сжатие галерей в этой работе не выполнялись. Измеренного прироста скорости по этим пунктам нет.

  • Отдельный этап

    Посадочные страницы услуг

    На сайте студии 26 содержательных страниц, услуги представлены разделом главной. Отдельные страницы под услуги и географические запросы пока не создавались. Их состав и тексты требуют отдельной проработки; количество страниц автосервиса не переносится на студию автоматически.

Проверка доступа ИИ на публичном адресе

Главная и контакты вернули HTTP 200 при запросах с каждым из шести User-Agent. Во всех ответах присутствует noindex, nofollow. Запросы выполнены из среды проверки, а не с IP-адресов провайдеров; это не подтверждение реального обхода или включения сайта в ИИ-поиск.

  1. Нужен доступ к хостингу

    Опубликовать файлы и разрешить индексирование

    Загрузить обновлённые файлы, удалить общий X-Robots-Tag: noindex, nofollow из настроек этого сайта и настроить /index.html → /. Проверить, что robots.txt, sitemap.xml и llms.txt возвращают 200. Неизвестный URL уже возвращает 404; нужно подключить фирменную страницу ошибки. Для nginx подготовлен пример конфигурации.

  2. Нужен доступ владельца

    Подключить поисковые кабинеты

    Подтвердить сайт в Яндекс Вебмастере и Google Search Console, отправить карту сайта и запросить переобход основных страниц. Коды подтверждения в файлы пока не добавлены.

  3. Нужен номер счётчика

    Настроить аналитику обращений

    Подключить Яндекс Метрику и цели на звонок, личный Telegram и MAX. Это позволит оценивать реальные обращения после запуска.

  4. После выбора домена

    Перенести SEO на постоянный адрес

    Обновить домен в настройках, сохранить пути страниц, настроить постраничные перенаправления со старого адреса и обновить поисковые кабинеты и ссылку в Яндекс Бизнесе.
