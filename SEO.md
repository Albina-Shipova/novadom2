# SEO сайта «Нова Дом»

Текущий основной адрес: https://novadom.asama.site/.

Клиентский отчёт: `seo-otchet.html`, оформление — `seo-otchet.css`. Страница имеет `noindex, follow`, не включается в sitemap и не добавлена в основную навигацию. При публикации отчёта загрузить оба файла вместе с сайтом.

## Что настроено

- Уникальные title и description на 26 страницах; описания проектов формируются из видимого содержания.
- Абсолютные canonical, Open Graph и Twitter Cards с фотографией каждой страницы.
- JSON-LD: Organization, WebSite, WebPage, ContactPage, CollectionPage, Service, BreadcrumbList и ItemList.
- robots.txt и sitemap.xml на все 26 страниц с основными изображениями. Даты изменения не выдумываются.
- Контент и ссылки доступны в исходном HTML; блоки reveal видны без JavaScript.
- Страница 404 с noindex. Хостинг должен возвращать для отсутствующих страниц HTTP 404, а не 200.
- Исправлены ошибочные телефонные ссылки в портфолио.
- Явные правила для шести агентов ChatGPT, Claude и Perplexity; исключения служебных путей повторены в специальной группе.
- llms.txt с фактами, услугами и ссылками на проекты; describedby-ссылка со всех 26 страниц. Файл генерируется вместе с остальным SEO.
- Видимые хлебные крошки, preload главных изображений, defer основного скрипта и SVG-фавикон.
- Производительность: заставка открывает страницу в плавном коротком ритме, Google Fonts загружаются параллельно с первым отображением, кадры слайдера подгружаются к показу, дипломы используют лёгкие превью с открытием оригинала по нажатию. Генератор SEO сохраняет актуальные версии CSS и JS в URL.
- Фирменное превью главной assets/client/og-novadom.jpg, 1200 × 630, около 137 КБ. Макет для повторного рендера — tools/og-preview.html.

Почтовый адрес, рейтинги и часы в разметку организации не добавлены: на сайте нет опубликованного адреса, актуальность старой карточки не проверена. Разметка проектов не приписывает студии авторство работ другого бюро.

## Обновление

После изменения текстов, добавления проектов или смены домена:

```powershell
python tools/seo.py
python tools/check_seo.py
```

Смена основного домена (заменить адрес на выбранный):

```powershell
python tools/seo.py --domain https://example.ru
python tools/check_seo.py
```

Команда сохраняет домен в seo-config.json и обновляет все абсолютные SEO-адреса. Она не меняет DNS, сервер и настройки поисковых кабинетов.

## Публикация и сервер

Публиковать корневые HTML, styles.css, script.js, favicon.ico, robots.txt, sitemap.xml, llms.txt, seo-otchet.css, 404.html и папку assets. Не публиковать .git, .responsive-audit, debug.log, tools, deploy, SOURCE_NOTES.md, SEO.md и seo-config.json. Запрет в robots.txt не заменяет исключение этих файлов из публикации. Отчёт не запрещён в robots.txt: роботу необходимо прочитать noindex из HTML.

На сервере настроить:

1. HTTP → HTTPS и альтернативные хосты → основной хост постоянным редиректом 301/308.
2. /index.html → / постоянным редиректом. Остальные URL .html сохранить: они используются в ссылках, sitemap и canonical.
3. Настоящий HTTP 404 с содержимым 404.html для отсутствующих адресов; не включать SPA-fallback на index.html.
4. HTML, CSS и JS с правильными MIME-типами, сжатие gzip/Brotli. HTML с перепроверкой кеша; длительный кеш неизменяемых изображений только при смене имени после изменения.
5. Проверить, что хостинг не добавляет X-Robots-Tag: noindex, robots.txt и sitemap.xml доступны без авторизации и возвращают 200.

Публичная проверка 11 ноября 2026: сервер nginx/1.18.0; HTTPS и переход HTTP → HTTPS работают; gzip включён для HTML, но CSS и JS отдавались без сжатия. Главная возвращала X-Robots-Tag: noindex, nofollow; robots.txt, sitemap.xml и llms.txt возвращали 404; /index.html отвечал 200 вместо редиректа. 12 ноября PageSpeed Insights измерил мобильную производительность 72 (FCP 2,3 с, LCP 5,9 с, TBT 0 мс, CLS 0), компьютерную 90 (FCP 0,4 с, LCP 1,8 с, TBT 20 мс, CLS 0,011), SEO 69 и подтвердил невозможность индексации. Это лабораторный замер одной загрузки; полевые данные пользователей не проверялись. Локальные оптимизации скорости внесены после этого замера, публичный повторный прогон ещё не выполнялся.

Для nginx подготовлен deploy/nginx-seo.conf.example: убрать общий noindex только у этого сайта, добавить редирект /index.html, фирменный 404, заголовок noindex для отчёта, ограничения на рабочие каталоги, сжатие текстовых типов и правила Cache-Control. Это пример для объединения с действующей конфигурацией, не полный виртуальный хост; перед перезагрузкой нужен nginx -t. Доступ к конфигурации сервера не предоставлен, изменения на хостинге не применялись. Длительное immutable-кеширование безопасно лишь после публикации соответствующих URL-версий файлов.

Команда `python tools/check_live_seo.py` выполняет повторную проверку; подробные результаты сохраняются в .responsive-audit/live-seo.json. Запросы с шестью User-Agent вернули 200 для главной и контактов, но с noindex. Такие запросы не подтверждают доступ с реальных IP провайдеров или присутствие в ИИ-ответах.

## PageSpeed Insights, 12 ноября 2026

Отчёты: [мобильный](https://pagespeed.web.dev/analysis/https-novadom-asama-site/v9kom2k76t?form_factor=mobile), [компьютер](https://pagespeed.web.dev/analysis/https-novadom-asama-site/v9kom2k76t?form_factor=desktop). Lighthouse 13.6.0. Полученные оценки: производительность 72/90, доступность 94, лучшие практики 100, SEO 69. Мобильный режим — Moto G Power с медленным 4G.

- Mobile: FCP 2,3 с, LCP 5,9 с, TBT 0 мс, CLS 0, Speed Index 5,5 с. Аудиты предполагают экономию около 1 100 мс на блокирующих запросах, 345 КиБ на изображениях и 848 КиБ на кеше.
- Desktop: FCP 0,4 с, LCP 1,8 с, TBT 20 мс, CLS 0,011, Speed Index 1,7 с. Аудиты предполагают экономию около 3 454 КиБ на кеше, 2 250 КиБ на изображениях и 230 мс на блокирующих запросах; общий сетевой объём — 3 574 КиБ.
- Диагностика обеих конфигураций указывает на неиспользуемый CSS, уменьшение CSS примерно на 25 КиБ и JS на 12 КиБ, а также нескомпонованные анимации. Сокращение заставки и отложенная загрузка изображений исправлены в локальных исходниках, но эти значения получены до их публикации и повторного замера.
- SEO-аудит говорит, что страница недоступна для индексации. Метатег `robots` в локальном HTML разрешает индексацию; ранее измеренный публичный заголовок `X-Robots-Tag: noindex, nofollow` имеет приоритет и должен быть удалён на сервере. После этого повторить PageSpeed и запросить переобход.

Лабораторные значения зависят от конкретного прогона. CrUX/полевые Core Web Vitals, поисковые позиции и органический трафик в этом аудите не измерены.

`llms.txt` — предложенный формат справочника, не обязательный стандарт и не гарантия попадания в ИИ-ответы. Правила ИИ-поиска не меняют политику обучения: отдельные настройки GPTBot/ClaudeBot не вводились, сохраняется действие общей группы. Инструкции провайдеров: [OpenAI](https://developers.openai.com/api/docs/bots), [Anthropic](https://privacy.claude.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler), [Perplexity](https://docs.perplexity.ai/docs/resources/perplexity-crawlers), [предложение llms.txt](https://llmstxt.org/).

## Поисковые кабинеты

После публикации подтвердить права на сайт в Яндекс Вебмастере и Google Search Console, отправить https://novadom.asama.site/sitemap.xml и запросить переобход главной, контактов и портфолио. Нужны аккаунты владельца и полученные в кабинетах коды проверки; случайные коды и идентификаторы аналитики в сайт не добавлены.

Подключать Яндекс Метрику после получения реального номера счётчика; цели: звонок, переход к личному Telegram и MAX. Актуализировать сайт в Яндекс Бизнесе. Проверить JSON-LD в Schema Markup Validator и поддерживаемые типы в Google Rich Results Test. Наличие разметки не гарантирует расширенный сниппет.

При переходе на постоянный домен сохранить пути страниц, поставить постраничные 301 со старого домена, обновить поисковые кабинеты, ссылку в Яндекс Бизнесе и повторно отправить sitemap. Если временный домен не должен попадать в поиск, это отдельное решение: текущая версия разрешает его индексацию.

Основание: [canonical](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls), [sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap), [структурированные данные](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data).
